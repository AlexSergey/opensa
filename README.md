# OpenSA

**This project is closed.** OpenSA was an open-source game engine, written from scratch in TypeScript, built
compatible with RenderWare (the engine behind GTA San Andreas) and running in the browser. It lived from
4 June 2026 to 25 August 2026. The source code and the demo are no longer available.

The full story - why it was closed, what was built, and what comes next - is in the blog:
